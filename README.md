# 百花学习与生活顾问系统 · 说明文档

面向高校学生的一站式校园生活与学业规划智能体（北京化工大学 · 信息科学与技术学院 2025 级培养方案已接入）。

## 一、PyCharm 运行步骤

1. **打开项目**：PyCharm → Open → 选择 `baihua-advisor` 文件夹。
2. **装依赖**：底部 Terminal 执行
   ```
   pip install -r requirements.txt
   ```
3. **启动**：右键 `app.py` → Run，浏览器打开 **http://127.0.0.1:8000**
   （或终端执行 `python app.py`）

## 四、一课堂 · 目标导向课程规划（本次新增链路）

流程严格按：**提问目标 → 取课程知识库 → 整合生成提示词 → 大模型出规划**

1. **识别目标**：保研 / 考研 / 出国 / 就业 / 转专业（问题文本优先，其次注册画像的学业目标）
   > 其中「保研 / 考研 / 出国 / 就业」已各自建成专题面板（政策解读 / 板块资料 / 项目检索 / 年级任务清单），点目标胶囊直接展开；「转专业」走政策+方案对比；其余目标走下方选课打分规划。
2. **外接课程知识库** `course_kb.json`：该专业大一~大四全部课程按学期排序，每门含
   `简介、学分、课时、难易度(易/中/难)、性质(必修/选修)、类别`；由 `scripts/build_course_kb.py` 从执行计划自动生成，补充专业后重跑即可
3. **提示词组装**（`planner.build_prompt`）：学生画像+毕业学分缺口+未修课程清单(JSON)+**三条硬约束**：
   - 满足学业总学分（毕业要求−已修，选修补足）
   - 课时适中（每学期 280–520 学时，毕业季学期除外）
   - 难易适中（每学期难课占比 ≤45%，难易搭配、为难课留复习周）
4. **生成规划**：有 `DASHSCOPE_API_KEY` → 大模型按提示词输出学期课表+每门课对目标的作用；无 Key → 本地规则引擎执行同一提示词的约束，结果确定性可演示
5. **可溯源**：图谱页「目标导向学业规划」面板展示规划正文，并可展开**查看本次发送给大模型的提示词**；问答里问"我想保研，怎么选课"也会走此链路，回答附来源卡（执行计划文件名）

## 五、转专业 · 政策要求 + 两方案对比（新增链路）

1. **政策要求**：读取 `transfer_rules.json`（《北京化工大学本科生转专业实施细则》），列出基本条件、
   三通道（学业优秀类 / 专长类 / 兴趣类）各自的硬性门槛与名额、限制与禁止情形（如四年级不考虑——自动按学生年级命中预警）
2. **方案对比**：自动对比转出/转入两个培养方案，输出**可认定课程、需补修课程、失效课程**三张明细表与学分缺口
3. **工作清单**：按官方时间线生成"申请→考核→公示→学籍变更→补修"步骤与考核准备建议
4. 问答里问"我想转到计算机"同样触发该链路

## 六、保研四通道 · 政策要求 + 画像自评（新增链路）

1. **四条通道**：普通学业推免 / 支教保研（研究生支教团）/ 行政保研（实践锻炼岗位）/ 直博推免，
   每条给出「硬性条件表（含特例降线）· 名额 · 优先加分项 · 流程时间节点 · 报名材料清单 · 最大风险点」
2. **共用地基与横向对比**：总览页用六维对比表（GPA/英语/排名/名额/加分项/风险）横向比较四条通道，并列出通道共用的硬性底线
3. **四年倒排路线**：大一 → 大二 → 大三上 → 大四 逐年任务清单（正考 GPA、六级 425、入党、教资、大创、联系导师）
4. **画像自评核对**：登录后填入 GPA / 六级 / 综合排名 / 学生干部 / 党员 / 志愿服务 / 教资 / 科研 / 已联系导师，
   系统逐条判定 ✅达标 · ❌未达 · ⚪待补，并附该项对应的政策说明与特例
5. **问答直达**：问"支教保研需要什么条件""直博要准备哪些材料""保研有哪几条路"自动命中对应通道，附政策原文出处
6. 政策依据：校教发〔2019〕23号、团发〔2024〕26号（第11届支教团）、2027年推免招生工作办法、信息学院2027推免实施细则
   （名额为文件当年口径，每年以最新通知为准）

## 七、考研六大板块 · 资料驱动（新增链路）

1. **入口**：目标导向规划选「考研」→ 展开六大板块：自身情况概览 / 考研基本常识 / 具体考试内容 /
   时间线及择校选专业 / 录取规则梳理 / 查信息防诈骗
2. **板块一 自身情况概览**：四类考生（大四应届/大三/大一大二/在职往届）× 距初试时间 × 当下要做的事，
   并列表格 + 两条硬性提醒（10月报名截止、以研招网公告为准）
3. **板块二 考研基本常识**：「考研到底是什么」——考试定义、核心结构（初试+复试=录取）、
   与高考三点不同（先填志愿只能一个、有调剂二次机会、复试占30%-50%非走过场）
4. **板块三 具体考试内容**：按资料 3.1-3.5 照搬——通用四科500分结构、数学一二三卷种占比、
   英语一二题型分值、政治模块与题型、专业课统考vs自命题，全部表格呈现
5. **板块四 时间线及择校选专业**：两个子选项——①考研时间线（以2027年为例，11阶段×官方流程×考生任务表）；
   ②择校选专业三层：决策顺序流程图（定专业→定城市→定层次→查数据）、择校必须看清的六个数据表、
   判断学校是否歧视本科的观察角度（4条判据+2条提醒）
6. **板块五 录取规则梳理**：两个子选项——①各类分数线（国家线/院校复试线/院系专业线/34所自划线
   三列表 + 递进关系与单科线两条重要提醒）；②总成绩计算规则（公式、50-70%权重、百分制折算、
   报名前必读复试录取办法）
7. **板块六 查信息防诈骗**：三个子选项——①查信息（6大权威渠道表含官方网址 + 10条高频踩坑清单）；
   ②防诈骗（4条防骗要点）；③行动清单（4阶段17项任务，勾选完成状态按账号持久保存，跨设备可见）
8. 问答里问"考研到底是什么""院系线和国家线区别""有哪些考研骗局"等直接命中对应板块；
   资料来源界面不标注，口径统一提示「以研招网/教育部公告为准」

## 九、出国留学 · 地区/学校检索（新增链路）

   点击展开 → 按国家分组列出所有合作学校 → 再点学校名展开，逐条列出该校每个项目的

## 十三、注意事项

- 课程简介与难易度为系统规则生成的通稿（以教学大纲为准）；先修关系由规则引擎推断；正式选课以教务系统为准——界面与提示词中均已注明
- 自动化类为分流前平台方案，规划会如实标注"知识库缺口"（分流后课程未列入原文件）
- 换 API Key：`config.py` 填 `DASHSCOPE_API_KEY`（阿里云百炼，新用户每模型 100 万 token 免费）；未填 Key 且未启动本地模型时，系统自动切换为**规则引擎兜底模式**，全部功能照常可演示
- 生活模块通用问答：知识库未覆盖的开放问题由大模型自由作答（标注「AI 通用建议」，禁止编造校内事实），支持多轮会话与「＋ 新对话」
