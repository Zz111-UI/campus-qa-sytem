## 一、《校园文明学生公约》

1. 热爱祖国，拥护党的领导，维护国家尊严和学校荣誉
2. 勤奋学习，刻苦钻研，遵守课堂纪律，不迟到、不早退、不旷课
3. 诚实守信，考试不作弊，论文不抄袭
4. 尊敬师长，团结同学，礼貌待人
5. 爱护公物，不乱涂乱画，不损坏公共设施
6. 讲究卫生，不乱扔垃圾，不随地吐痰
7. 遵守秩序，不在公共场所大声喧哗
8. 勤俭节约，不浪费粮食，不攀比消费
9. 遵纪守法，不参与违法违纪活动
10. 积极向上，踊跃参加社会实践和志愿服务

## 二、《北京化工大学校园管理规定》

### （一）校园秩序
1. 学生应遵守校园管理规定，维护校园正常秩序
2. 不得在校园内从事影响教学、科研和生活秩序的活动
3. 校园内禁止酗酒、打架斗殴、赌博、吸毒等违法行为

### （二）校园环境
1. 不得私设摊点、乱贴广告
2. 不得在建筑物、构筑物、地面、山石、设施、树木上涂写刻画
3. 不得随地吐痰、便溺，不得乱扔果皮、烟头、口香糖等废弃物
4. 校园行车限速**5公里/小时**，禁止鸣笛

### （三）校园安全
1. 禁止携带易燃、易爆、有毒等危险品进入校园
2. 禁止在校园内饲养犬类、鸽子等动物
3. 禁止翻越水域护栏
4. 禁止在非指定区域燃放烟花爆竹

### （四）校园活动
1. 举办大型活动须经学校批准
2. 不得在校园内从事商业经营活动（经学校批准的除外）
3. 社团活动须遵守学校社团管理规定

## 三、《北京化工大学学生公寓管理规定》

### 第一章 总则

- 学生公寓是学生在校期间学习、生活的重要场所
- 公寓管理坚持"以人为本、服务学生、规范管理、安全第一"的原则

### 第二章 入住与退宿

#### 第三条 入住
1. 新生入学后由学校统一安排住宿
2. 学生应按指定房间、床位入住，不得私自调换
3. 入住时须办理入住登记手续

#### 第四条 退宿
1. 学生毕业、退学、休学应办理退宿手续
2. 退宿时应结清费用，交还钥匙，保持房间整洁
3. 住宿费按学年收取，退宿按月计退

### 第三章 作息时间

#### 第五条 公寓开门关门时间
- **开门时间**：6:00
- **关门时间**：23:00

#### 第六条 供电时间

| 学生类型 | 周日至周四 | 周五至周六 |
|---|---|---|
| 本科生 | 23:00～次日6:00断电 | 24:00～次日6:00断电 |
| 昌平一期本科生 | 每天23:00断电 | 每天23:00断电 |
| 研究生 | 全天供电 | 全天供电 |

### 第四章 会客管理

#### 第七条
1. 会客时间一般为**8:00～22:00**
2. 会客不超过**2小时**
3. **22:00后一般不可会客**
4. 严禁留宿异性
5. 校外人员会客须登记

### 第五章 安全管理

#### 第八条 消防安全
1. 严禁在公寓内吸烟
2. 严禁使用明火
3. 严禁私拉电线
4. 严禁使用违章电器

#### 第九条 禁用电器清单（完整）
以下电器严禁在公寓内使用：
- 电加热器
- 卷发棒
- 微波炉
- 电磁炉
- 电水壶
- 电褥子
- 咖啡机
- 电饭煲
- 洗衣机
- 冰箱
- 其他大功率电器

> 注：吹风机可存放但禁止使用。

#### 第十条 治安管理
1. 离开房间应锁门
2. 妥善保管个人财物
3. 不得将房间钥匙转借他人
4. 发现可疑人员应及时报告

### 第六章 卫生管理

#### 第十一条
1. 保持房间整洁，定期打扫
2. 垃圾应分类投放
3. 不得在公寓内饲养宠物
4. 不得在公寓内从事商业活动

### 第七章 违纪处理

#### 第十二条
违反公寓管理规定的，视情节轻重给予以下处理：
1. 批评教育
2. 通报批评
3. 纪律处分（警告至开除学籍）
4. 取消住宿资格

## 四、公寓附件

### 附件一：住宿流程
1. 新生报到时到所在院系领取住宿通知单
2. 持住宿通知单到公寓管理站办理入住手续
3. 领取钥匙，入住指定房间
4. 入住后检查房间设施，如有损坏及时报告

### 附件二：消防管理规定
1. 熟悉公寓内消防设施位置和使用方法
2. 熟悉疏散通道和安全出口
3. 不得堵塞疏散通道
4. 不得损坏消防设施
5. 发现火灾隐患及时报告

### 附件三：文明公约
1. 团结友爱，互帮互助
2. 保持安静，不影响他人休息
3. 节约用水用电
4. 爱护公共设施
5. 尊重公寓管理人员

## 五、《北京化工大学校园垃圾管理规定》

1. 校园内实行垃圾分类投放
2. 垃圾应投放到指定垃圾桶内
3. 不得随意丢弃垃圾
4. 不得从窗户向外抛扔垃圾
5. 公寓内垃圾应袋装后投放到楼下垃圾桶
6. 违反规定的，视情节给予批评教育或纪律处分

## 六、《北京化工大学控烟管理办法》

### （一）禁烟区域
1. 所有室内公共场所
2. 未标明吸烟区的室外区域
3. 教学楼、图书馆、实验室、食堂、公寓等

### （二）吸烟区设置
东校区设6处吸烟区：
1. 足球场东门外
2. 东篮球场北门外
3. 其他指定区域（详见校园标识）

### （三）违规处理
| 违规次数 | 处理 |
|---|---|
| 首次 | 批评教育 |
| 第二次 | 警告处分 |
| 第三次 | 严重警告处分 |
| 屡教不改 | 记过以上处分 |

### （三）公费医疗报销比例

| 就医类型 | 个人负担比例 |
|---|---|
| 校医院门诊 | 5% |
| 合同医院门诊 | 10% |
| 住院 | 5% |
| 非合同医院 | 20%～30% |
| 注明部分自付的药品/检查 | 另加5% |
| 全自付项目 | 不予报销 |

### （四）报销时限
- 北京市内住院：费用发生后**2个月内**办理报销
- 外埠住院：费用发生后**5个月内**（不超过下年2月底）办理报销

### （五）不予报销的情形
1. 未经校医院转诊私自在校外看病（急诊除外）
2. 因交通肇事、打架斗殴、酗酒、自杀、医疗事故造成的费用
3. 美容、整容、矫形、健美相关费用
4. 用于科学研究的医药费
5. 各种体格检测费
6. 公费医疗用药目录以外的药品
7. 寒暑假期间在家庭所在地非急诊看病
8. 外地实习期间在私立医院、部队医院看病

### （六）新生入学体检
- 新生须参加入学体检
- 体检合格后方可享受公费医疗待遇
- 体检不合格的，按学校相关规定处理
