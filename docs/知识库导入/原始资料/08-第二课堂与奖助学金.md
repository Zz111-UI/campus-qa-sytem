# 北京化工大学2025级本科生手册（八）

## 第二课堂成绩评定与奖助学金体系

---

## 一、第二课堂成绩评定实施办法

### 成绩构成（满分600分）

| 维度 | 分值上限 | 基础评定(80%) | 拓展评定(20%) |
|---|---|---|---|
| 道德与思想素质 | 180分 | 144分 | 36分 |
| 学术与科技创新 | 120分 | 96分 | 24分 |
| 体育与身心健康 | 100分 | 80分 | 20分 |
| 美学与人文素养 | 100分 | 80分 | 20分 |
| 劳动与社会实践 | 100分 | 80分 | 20分 |

### 各维度拓展加分要点

**道德与思想素质：**
- 党校团校学习结业：+10分
- 校级以上优秀党员/团员/学生干部：+10～20分
- 志愿服务：每小时+1分，上限20分

**学术与科技创新：**
- 学科竞赛获奖：校级+5～10，省部级+10～15，国家级+15～20
- 大创项目：校级+5，市级+8，国家级+10
- 发表论文：+10～20分
- 专利授权：+10～15分
- 学术讲座：每次+1分，上限10分

**体育与身心健康：**
- 体育竞赛获奖：校级+5～10，省部级+10～15，国家级+15～20
- 体测优秀：+10分
- 心理健康活动：每次+2分，上限10分

**美学与人文素养：**
- 文艺比赛获奖：校级+5～10，省部级+10～15，国家级+15～20
- 文艺演出展览：每次+3分，上限15分
- 人文讲座：每次+1分，上限10分

**劳动与社会实践：**
- 社会实践获奖：校级+5～10，省部级+10～15，国家级+15～20
- 勤工助学：每学期+5分
- 志愿服务：每小时+1分，上限15分

### 成绩使用
- 评奖评优、推优入党、推荐免试研究生、毕业生鉴定、就业推荐的重要依据

## 二、国家奖学金

- **金额**：8000元/年
- **条件**：学习成绩排名与综合考评均位于前5%（突出者前30%）
- **评审**：公开答辩+无记名投票
- **公示**：不少于5个工作日
- **发放**：一次性发放到校园卡

---

## 三、国家励志奖学金

- **金额**：5000元/年
- **条件**：家庭经济困难 + 学习成绩排名前25%（突出者前50%）
- **限制**：二年级以上方可申请
- **公示**：不少于5个工作日

---

## 四、人民奖学金（每学期）

| 等级 | 金额 | 比例 |
|---|---|---|
| 一等奖 | 1000元/学期 | 2% |
| 二等奖 | 600元/学期 | 7% |
| 三等奖 | 400元/学期 | 10% |
| 单项奖 | 300元/学期 | 3% |

### 成绩构成
```
人民奖学金成绩 = 学习成绩70% + 第二课堂成绩30%
```

## 五、社会资助奖学金

- 企事业单位、社会团体或个人设立
- 常见：化工出版社奖学金、中国石化奖学金、巴斯夫奖学金等
- 各设立单位制定具体条件
- 一般要求学习成绩优良、家庭经济困难或特定专业

## 七、校长奖

- 全校每年评选不超过**5人**
- 在学术研究、科技创新、社会实践、志愿服务等方面有突出贡献
- 公开答辩，校长办公会批准

---

## 八、奖学金兼得规则

| 组合 | 是否可兼得 |
|---|---|
| 国家奖学金 + 国家励志奖学金 | 不可 |
| 国家奖学金 + 人民奖学金 | 不可 |
| 国家奖学金 + 社会资助奖学金 | 不可 |
| 国家励志奖学金 + 人民奖学金 | 不可 |
| 国家奖学金/励志奖学金 + 国家助学金 | **可兼得** |
| 素质拓展竞赛奖 + 其他奖学金 | 可兼得 |
| 校长奖 + 其他奖学金 | 可兼得 |

## 九、家庭经济困难学生认定

### 认定等级
- **特别困难**：家庭经济收入极低，基本生活难以维持
- **困难**：家庭经济收入较低，不能完全负担学习生活费用
- **一般困难**：家庭经济收入偏低，部分负担有困难

### 认定程序
1. 学生自愿申请，提交认定申请表及证明材料
2. 班级民主评议
3. 院系认定工作组审核
4. 公示不少于5个工作日
5. 学校学生资助管理中心审批

### 动态管理
- 每学年认定一次
- 家庭经济状况变化可随时申请调整
