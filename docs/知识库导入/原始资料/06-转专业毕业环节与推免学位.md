# 北京化工大学2025级本科生手册（六）

## 转专业、毕业环节、推免与学位授予

---

## 一、本科生转专业实施细则

### 可申请条件

**（一）学业优秀类**
- 已修课程正考GPA**不低于3.0**

**（二）兴趣专长类**（具备以下之一）
- 省部级及以上与拟转入专业相关竞赛奖励
- 拟转入专业领域突出成果（论文、专利等）
- 预修拟转入专业相关课程≥5学分且成绩优良

**（三）国家政策类**
- 应征入伍退役复学后
- 休学创业复学后创业项目优秀
- 同等条件下优先接收

**（四）特殊困难类**
- 入学后发现疾病或生理缺陷，经指定医院证明不能在原专业学习

**（五）对专业不感兴趣类**
- 可申请转入学校指定部分专业，不限定分数

### 不予考虑情形
1. 休学或保留学籍期间
2. 特殊招生形式录取（高水平运动队、定向委培、保送生等）
3. 正在受纪律处分期间
4. 四年级及以上
5. 已转过专业
6. 其他不适合转专业情形

### 考核方案
- **正考GPA占30%** + **笔试占30%**（≥60分钟）+ **面试占40%**（≥10分钟）
- 笔试面试全程录像，保存至少1年

### 接收计划
- 各专业接收后学生总数不超过当年招生计划数的**10%**
- 拟接收名单公示3个工作日

## 二、学位论文学术道德和学术规范实施办法

### 检测系统
- 中国知网"大学生论文检测系统"
- 每篇限检测**2次**

### 文字复制比标准

| 复制比 | 处理 |
|---|---|
| ≤20% | 通过，可参加评阅答辩 |
| 20%-30% | 修改后由指导教师和评阅人审核通过可参加 |
| 30%-50% | 取消本次答辩资格，一周内二次查重，仍不合格取消毕业资格 |
| >50% | 直接取消本次毕业资格，成绩0分，一年后重新申请 |

### 其他规定
- 复制比>20%不能评为优秀论文
- 答辩后抽查>20%取消学位授予资格
- 学术不端按纪律处分规定处理

## 三、本科生毕业环节工作规定

### 选题
- 符合专业培养目标，尽可能结合科研生产实际
- 一人一题，团队项目明确每人独立部分
- 选题确定后不得随意更换

### 指导教师
- 讲师以上或硕士以上学位
- 每位导师同时指导≤**8人**
- 每周指导≥2次，每次≥2学时

### 过程管理
- 2周内完成开题报告
- 中期检查进展
- 取消答辩资格：未完成任务、缺勤超1/3、严重学术不端、严重违纪

### 答辩
- 答辩小组≥3名教师
- 实行**指导教师回避制**
- 学生汇报10-15分钟，提问回答10-15分钟

### 成绩构成

| 环节 | 占比 |
|---|---|
| 指导教师评分 | 30% |
| 评阅人评分 | 20% |
| 答辩成绩 | 50% |

### 优秀比例
- 优秀≤15%（示范专业最多20%）
- 优秀+良好≤70%

## 四、推荐免试攻读研究生管理规定

### 基本条件（须同时满足）
1. 应届本科毕业生（不含第二学士学位、专升本、定向）
2. 前三年所修课程全部通过（含补考重修通过）
3. 前三年正考GPA**≥3.00**
4. 无考试作弊和剽窃记录
5. 无违法违纪受处分记录
6. **六级≥425分**（小语种/英语专业相应标准）
7. 体测达标

### 推免总成绩
```
推免总成绩 = 学业成绩80% + 第二课堂成绩20%
```

### 推免类别
- **普通推免**：按总成绩排名，正考GPA≥3.00
- **专项推免**：支教团、高水平运动队等，总成绩排名须在专业前50%

### 推免后管理
- 须在"推免服务系统"填报志愿
- **获得推免资格不得再报名研究生入学考试**
- 取消资格情形：未取得毕业证、受纪律处分、弄虚作假、毕设严重学术不端

## 五、学位授予实施细则

### 学士学位授予条件
1. 修完培养方案全部内容达到毕业要求
2. **课程（不含毕设）最高GPA≥2.00**
3. **毕业设计（论文）GPA≥2.00**
4. 德育合格
5. 无未解除纪律处分

### 不授予学位情形
- 未达毕业要求
- 课程最高GPA<2.00
- 毕设GPA<2.00
- 留校察看及以上处分未解除
- 毕设严重学术不端
- 学位评定委员会认为不应授予的其他情形

### 双学位/辅修学位
- 双学位只发一本学历和学位证书，两个学位在证书注明
- 辅修学士学位在主修证书中注明，不单独发证

---

## 六、辅修学士学位管理办法

### 申请条件
- 全日制本科一年级学生（不含双学位、联合培养）
- 主修已修课程GPA**≥2.5**
- 每生只能修读一个辅修专业
- 辅修专业须与主修归属不同专业大类

### 修读要求
- 总学分**45-50学分**
- 修读年限一般**3年**
- 录取≥40人单独编班
- 学费**150元/学分**

### 学籍管理
- 主修GPA低于2.0终止辅修资格
- 可申请终止辅修，已修课程作为选修课记载
