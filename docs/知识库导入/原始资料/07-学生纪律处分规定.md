# 北京化工大学2025级本科生手册（七）

## 学生纪律处分规定

---

## 一、处分种类（5级）

| 等级 | 处分 | 期限 |
|---|---|---|
| 1 | 警告 | 一般12个月 |
| 2 | 严重警告 | 一般12个月 |
| 3 | 记过 | 一般12个月 |
| 4 | 留校察看 | 一般12个月（可延长6个月，仅一次） |
| 5 | 开除学籍 | / |

## 二、打架斗殴

| 行为 | 处分 |
|---|---|
| 动手打人未致伤 | 警告至记过 |
| 致他人轻伤 | 记过至留校察看 |
| 致他人重伤 | 留校察看或开除学籍 |
| 持械斗殴未致伤 | 记过至留校察看 |
| 持械斗殴致伤 | 留校察看或开除学籍 |
| 组织策划聚众斗殴 | 留校察看或开除学籍 |
| 积极参与聚众斗殴 | 记过至留校察看 |
| 提供凶器 | 记过至留校察看 |

> 致轻伤以上移交公安机关

### 勒索
| 金额 | 处分 |
|---|---|

| 200-2000元 | 记过以上 |
| >2000元 | 留校察看或开除学籍 |

### 侵占
| 金额 | 处分 |
|---|---|
| <1000元 | 警告或严重警告 |

## 四、考试违纪与作弊

### 考试违纪（警告至记过）
1. 携带规定以外物品未放指定位置
2. 未在规定座位考试
3. 开考信号前答题或结束后继续答题
4. 旁窥、交头接耳、互打暗号手势
5. 喧哗吸烟或影响考场秩序
6. 未经同意擅自离开考场
7. 将试卷答卷草稿纸带出考场
8. 用规定以外笔纸答题或在规定以外地方书写信息
9. 其他违反考场规则尚未构成作弊

### 考试作弊（留校察看）
1. 携带与考试内容相关材料
2. 抄袭或协助他人抄袭
3. 抢夺窃取他人试卷或胁迫他人提供方便
4. 故意销毁试卷答卷或考试材料
5. 答卷填写与本人身份不符信息
6. 传接物品或交换试卷答卷草稿纸
7. 评卷中认定试卷雷同
8. 其他不正当手段获得试题答案或成绩

### 严重作弊（开除学籍）
1. 盗窃试卷
2. 替考或由他人替考
3. 组织作弊
4. 出售试题或答案牟取利益
5. 使用通讯设备或其他器材作弊
6. 再次作弊
7. 其他严重作弊或扰乱考试秩序

## 五、学术不端

- 剽窃抄袭情节较轻：严重警告至记过
- 剽窃抄袭情节较重：记过至留校察看
- 论文成果抄袭篡改伪造情节严重：**开除学籍**
- 代写论文、买卖论文：**开除学籍**
- 组织代写论文：留校察看或开除学籍

## 六、违反公寓管理

### 一般违规（警告至严重警告）
- 未经批准夜不归宿
- 未经批准留宿校外人员
- 大声喧哗影响他人休息经教育不改
- 饲养宠物
- 从事商业活动
- 使用违章电器

### 严重违规（记过至留校察看）
- 留宿异性
- 酗酒赌博
- 私拉电线使用明火造成安全隐患
- 使用违章电器引发火灾
- 多次违反经教育不改

## 七、违反网络管理

- 制作传播计算机病毒
- 未经允许进入或使用计算机信息网络资源
- 未经允许对网络功能/数据/程序进行删除修改增加
- 故意制作传播淫秽暴力恐怖有害信息
- 利用网络侮辱他人或诽谤他人
- 利用网络诈骗盗窃
- 情节严重构成犯罪移交司法机关

## 八、其他违纪

- 参与赌博：警告至记过；组织赌博：记过至留校察看；再次赌博：留校察看或开除
- 吸毒：**开除学籍**
- 卖淫嫖娼：**开除学籍**
- 参与非法传销：警告至记过；组织非法传销：**开除学籍**

## 九、旷课

| 旷课学时 | 处分 |
|---|---|
| 20-30 | 警告 |
| 31-40 | 严重警告 |
| 41-50 | 记过 |
| 51-60 | 留校察看 |
| >60 | 开除学籍 |

> 擅自离校连续4天警告，连续10天留校察看

## 十、处分程序

- 调查取证，听取学生陈述申辩
- 警告/严重警告：院系审批，报学工办备案
- 记过：院系审核，学工办审批
- 留校察看：院系审核，学工办审批，主管校领导批准
- 开除学籍：院系审核，学工办审查，校长办公会研究决定
- 开除学籍处分前应告知学生有要求听证的权利

## 十一、申诉

- 接到处分决定书**10日内**向学生申诉处理委员会书面申诉
- 委员会**15日内**作出复查结论，复杂可延长15日
- 对复查决定有异议**15日内**向北京市教委申诉
- 申诉期间不停止原处分执行
