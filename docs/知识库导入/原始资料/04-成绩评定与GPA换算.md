# 北京化工大学2025级本科生手册（四）

## 课程成绩评定与管理办法

---

## 一、成绩评定

### 总评成绩构成
- 过程性考核（平时作业、阶段测验、期中、上机）+ 结果性考核（期末）
- 期末考核成绩占比**不得高于70%**，一般50%-70%
- 开课时向学生公布总评成绩构成和各部分占比

### 记分方式
1. 百分制
2. 字母制
3. 两级制

### 成绩标记
正考、补考、重修、外校、缓考、缺考、违纪、作弊、取消、免体、免训

## 二、特殊情况成绩记载

### 补考
- 补考成绩按卷面成绩记载，标记"补考"
- 确认参加补考未参加的记0分，标记"缺考"

### 缓考
- 当学期期末和总评均记载"缓考"
- 补考前总评按0分计算GPA
- 补考获得的成绩记为正考学期成绩，标记"正考"
- 未参加补考记0分，标记"缺考"

### 缺考/违纪/作弊
- 未申请缓考未参加期末：总评0分/F/不合格，标记"缺考"
- 违纪：总评0分，标记"违纪"
- 作弊：总评0分，标记"作弊"

### 重修
- 跟班重修：过程+结果综合评定
- 自修重修：按期末成绩评定
- 均标记"重修"，多次重修取最高成绩

### 体育/体测/军训
- 身体残疾或体弱可申请体育保健课（成绩D）或免修（成绩P，标记免体）
- 免修军事技能成绩P，标记免训

### 公共英语免修与替换
- **免修条件**：四级≥560 / 托福≥80 / 雅思≥6，可免修当学期及以后公共英语
- **成绩替换**：四级≥425可在毕业学期替换低于60分的英语成绩为60分

## 三、成绩录入与提交

- 过程性和结果性成绩均录入教务系统
- 课程考核后**3个工作日内**完成成绩录入提交
- 提交后不得随意更改
- 成绩异议：公布后5个工作日内向院系申请复议，对结果有异议向教务处申请

## 四、GPA计算

### 公式
```
GPA = Σ（课程绩点 × 课程学分）÷ Σ课程学分
```

### 三种统计形式
1. 全部成绩GPA
2. 最高成绩GPA
3. 正考成绩GPA（专业排名依据）

### 不参与GPA计算
素质教育课程、两级制课程、体育课程
